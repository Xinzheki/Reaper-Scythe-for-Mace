Reaper's Scythe - Crimson edition (Minecraft Java 1.21.11) - resource pack only, no data pack needed.

* Mace -> 3D bone-and-rose reaper scythe.
* Hit particles (crit, enchanted_hit, damage_indicator) -> flaming dark-crimson skulls.
  Mace smash attacks and jump-crits spawn the most (a falling mace hit is a crit). Enchanted weapons add more.
* The big 'gust' particle (Wind Burst mace smashes, wind charges) -> crimson shock ring.
* Attack sounds and mace smash sounds -> glitchy electric soul-scythe hits.

These use the game's own hit effects, so they show for any weapon and any target.
